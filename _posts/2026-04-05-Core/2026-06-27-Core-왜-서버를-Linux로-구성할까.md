## 1. 서버란?
많은 사람들이 컴퓨터 한대라고 칭하지만 그건 절반만 맞는 말이다. 더 정확하게 말하면, 네트워크를 통해 다른 프로그램에게 서비스를 제공하는 시스템이다. 즉, 서버는 역할(Rule)을 의미한다.  
예를 들어 내가 만든 자바 프로그램이 사용자로부터 요청을 받고 처리하고 응답을 준다면 이 JAVA 프로그램을 서버라고 부른다.  
서버는 꼭 큰 컴퓨터일 필요가 없다. 맥북에서 `java -jar app.jav`를 실행하고 브라우저에서 `http://localhost:8080` 으로 접속하면 내 맥북이 웹 서버가 된 것이다.  
웹 서버란 서버 중에서도 HTTP 요청만 처리하는 서버를 말한다.

## 2. 왜 리눅스를 선택할까? 
우리가 쓰는 피씨는 바탕화면, 폴더 등 화면이 필요하다. 하지만 서버는? 자바, 톰캣 등을 실행만 하면 된다. 사람이 서버 앞에 앉아서 마우스를 움직일 일이 거의 없다. 보통은 원격 접속한다. GUI 없이 돌아가는 데 최적화되어 있다.  
또한, 운영체제의 일이 다르다. 운영체제가 하는 일은 메모리 관리, CPU 관리 등 이다. 예를 들어 사용자가 동시에 여러명 접속했다면 운영체제가 Thread 생성, 메모리 할당 등의 서버 작업을 해야 한다. 이런 서버 작업에 리눅스가 최적화 되어있다.  
대부분의 서버 프로그램이 리눅스 기준이기도 하다. Docker, Redis, Kafka 등의 프로그램들이 거의 전부 리눅스에서 가장 먼저 개발된다. 그래서 리눅스에서 가낭 성능도 좋고 자료도 많다. 자바나 스프링도 다르지 않다.  
리소스를 적게 먹는다. 같은 메모리여도 OS가 잡아먹는 리소스가 적다.  
재부팅이 거의 없다. 
이러한 이유로 개발자들은 유닉스 계열 운영체제인 맥을 선호한다. 맥 터미널에서 쉘 스크립트를 사용하는 방식이 리눅스와 거의 동일하기 때문이다. 

## 3. 윈도우는 왜 데스크톱에 강할까?
OS마다 애초에 만들어진 목적이 다르다. 윈도우는 사람을 위한 운영체제다. 사람이 컴퓨터를 편하게 쓰자가 목표였다. 철학이 다르다.
