title: \[Case/DB\] 외부 API 호출로 인한 DB 커넥션 풀 고갈 문제
---

## 1. 문제 상황

-   특정 거래(BFN 계열)에서 외부 기관 API 호출 수행

### 처리 흐름

1.  DB insert
2.  외부기관 API 호출 (응답 오래 걸림)
3.  결과 수신 후 DB 저장

### 발생 문제

-   동시에 30\~50건 요청 발생
-   DB 커넥션 풀이 부족하여 대기 발생

------------------------------------------------------------------------

## 2. 원인 분석

### WAS:

-   트랜잭션 유지 상태에서 외부 API 호출 수행

### DB:

-   커넥션 풀 고갈
-   세션 대기 발생

### 코드:

``` java
Connection conn = dataSource.getConnection();

try {
    insert();
    callExternalApi();
    update();
} finally {
    conn.close();
}
```

👉 문제 - 외부 API 호출 동안 DB 커넥션 점유 - 긴 트랜잭션 유지

------------------------------------------------------------------------

## 3. 해결 방법

### 1) 트랜잭션 분리

1.  요청 정보 DB 저장
2.  외부 API 호출
3.  결과 저장

------------------------------------------------------------------------

### 2) 커넥션 점유 시간 최소화

-   DB 작업 시에만 커넥션 사용

------------------------------------------------------------------------

## 4. 결과

-   DB 커넥션 풀 고갈 현상 해소
-   세션 대기 감소
-   동시 처리 성능 개선

------------------------------------------------------------------------

## 5. 배운 점

-   외부 API 호출을 트랜잭션 안에서 처리하면 위험하다
-   트랜잭션 범위를 최소화하는 것이 중요하다

------------------------------------------------------------------------

## 6. 추가 정리

-   커넥션 풀 = 동시에 DB와 연결 가능한 최대 수
